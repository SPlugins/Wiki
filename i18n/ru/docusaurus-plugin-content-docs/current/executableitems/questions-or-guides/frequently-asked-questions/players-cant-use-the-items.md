# Игроки не могут использовать предметы

Если вы уже создали свои предметы и хотите протестировать их с игроком без op и без прав, он попытается их использовать и получит это сообщение:

![](https://media.ssomar.com/m/docs-img-image-109.png)

Это происходит потому, что у него нет прав на использование предметов. Поскольку никто не хочет выдавать op своим игрокам, вам нужно выдать правильные права вашим обычным игрокам. Для этого просто откройте раздел [**Permissions**](https://splugins.net/docs/executableitems/commands-and-permissions#permissions) и прочитайте Tip в верхней части страницы ^^

Это изображение:

:::info
На всякий случай, **ДА**, для управления правами игроков на предметы необходим плагин для управления правами.

\
**Если у вас НЕТ ПЛАГИНА ДЛЯ ПРАВ и вы НЕ ХОТИТЕ его устанавливать, единственный способ, это выдать op вашим игрокам. Если вы этого не хотите, просто скачайте плагин для прав**
:::
