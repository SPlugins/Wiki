# Кастомный крафт

## Поддерживает ли ExecutableItems кастомный крафт?

ExecutableItems **не** имеет встроенных механик кастомного крафта. Чтобы создавать кастомные рецепты для ExecutableItems, вам нужно использовать сторонний плагин для кастомного крафта.

Вы можете использовать наш плагин [ExecutableCrafting](https://modrinth.com/plugin/executablecrafting)
Но если вы хотите использовать другой, это тоже возможно, как правило, они совместимы с ExecutableItems.
