# Кастомные дропы

:::danger
ЭТО РУКОВОДСТВО ПРЕДНАЗНАЧЕНО ДЛЯ EXECUTABLEITEMS, ЭТО ЗНАЧИТ, ЧТО **ЭТИ ДРОПЫ НЕ РАБОТАЮТ ГЛОБАЛЬНО**, ОНИ РАБОТАЮТ ТОЛЬКО ЕСЛИ У ВАС В ИНВЕНТАРЕ ЕСТЬ EXECUTABLEITEM.

\
ЕСЛИ ВЫ ХОТИТЕ СОЗДАТЬ ГЛОБАЛЬНЫЙ КАСТОМНЫЙ ДРОП, ИСПОЛЬЗУЙТЕ **EXECUTABLEEVENTS**
:::

Если вы хотите создать кастомные дропы, сначала нужно определить тип дропа. Будут объяснены оба варианта:

## Дропы с сущностей

Используйте активатор PLAYER\_KILL\_ENTITY или PLAYER\_KILL\_PLAYER, и в качестве команд вы можете использовать либо:

* Команды EI для дропа предметов
  * DROPEXECUTABLEITEM
  * DROPEXECUTABLEBLOCK
  * DROPITEM
* Ванильные команды для дропа предметов
  * Хорошим примером этого было бы выдать ГОЛОВУ игрока (PLAYER)
    * execute at %player% run summon item %target\_x\_int% %target\_y\_int% %target\_z\_int% \{Item:\{id:"player\_head",Count:1b,tag:\{SkullOwner:"%target%"\}\}\}

:::info
Не забывайте, что если вы хотите, чтобы эта команда срабатывала не на 100%, вы можете задать для неё шансы! Просто посмотрите на вики, там это уже объяснено ^^
:::

## Дропы с блоков

Используйте активатор PLAYER\_BREAK\_BLOCK, и в качестве команд вы можете использовать либо:

* Команды EI для дропа предметов
  * DROPEXECUTABLEITEM
  * DROPEXECUTABLEBLOCK
  * DROPITEM
* Ванильные команды для дропа предметов
  * Ванильная команда для дропа более чем одного предмета при разрушении (этот пример выдаёт 2 дополнительных предмета, вы можете сделать это случайным, используя вместо "2" плейсхолдер RNG)
    * execute at %player% run summon minecraft\:item %block\_x\_int% %block\_y\_int% %block\_z\_int% \{Item:\{id:"minecraft:%block\_item\_material\_lower%",Count:2b\}\}

:::info
Не забывайте, что если вы хотите, чтобы эта команда срабатывала не на 100%, вы можете задать для неё шансы! Просто посмотрите на вики, там это уже объяснено ^^
:::
