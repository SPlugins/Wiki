# Эпичные частицы

На этой странице вы узнаете разные методы добавления частиц к вашему предмету, от самых базовых до более эпичных/продвинутых.

### 1) Команда PARTICLE

Эта команда имеет ограничения по форме, например, в случае с частицей dust она работает не очень хорошо и т.д., именно поэтому она не является лучшим вариантом, вы можете посмотреть эту ссылку

[**КОМАНДА PARTICLE EI**](/tools-for-all-plugins/custom-commands/player-and-target-commands#particle)

### 2) Vanilla-команда particle

Комбинируя эту команду с туториалом "[**как использовать vanilla-команды**](executableitems/questions-or-guides/frequently-asked-questions/how-to-use-vanilla-commands)" вы получите что-то вроде

```
execute at <placeholder> run particle....
```

Здесь у вас больше свободы, чем в предыдущем варианте, но опять же, форма представляет собой только параллелепипед, не самое эпичное решение.

Если вы не знаете, как использовать команду particle, посмотрите эту ссылку

[**Как использовать команду particle**](/executableitems/questions-or-guides/utilities#general-particle-cmd)

[**Генератор команд particle**](https://www.gamergeeks.net/apps/minecraft/particle-command-generator)

### 3) Генераторы частиц

Здесь вы найдете несколько веб-страниц для генерации форм частиц, они ОЧЕНЬ полезны для создания контента.

Большинство из них работают на основе математических уравнений, поэтому вам понадобятся некоторые базовые знания в этой области. Чтобы посмотреть, как работают математические уравнения, вы можете использовать GEOGEBRA

Чтобы извлечь команды из одной строки или преобразовать функцию в разделённые команды, также потребуются некоторые базовые знания.

[**Первая ссылка**](https://100awesome.net/videos/particle-generator/) это генератор частиц на основе одного командного блока, там также есть видеотуториал

[**Вторая ссылка**](https://cloudwolfyt.github.io/pages/gens/particle-plots.html) лучше, она работает с математическими уравнениями, поэтому вы можете получить гораздо больше форм, чем в предыдущем варианте. Также есть [**видеоссылка**](https://youtu.be/\_mi1B0IeVWw).

### 4) Score particles

Также существуют Score particles, которые включают множество готовых форм, которые можно редактировать с помощью их специфических параметров, чтобы отобразить то, что вы хотите. Больше информации в туториале [**Score particles**]/tools-for-all-plugins-score/score-particles.md).
