# Добро пожаловать в вики Score Plugins

Добро пожаловать в полную документацию по всем Score Plugins!

Здесь вы найдёте подробную информацию о:

## 🎮 Основные плагины

- **ExecutableItems** - Создавайте кастомные предметы с уникальными способностями и командами
- **ExecutableBlocks** - Создавайте кастомные блоки со специальными функциями
- **ExecutableEvents** - Создавайте кастомные события и триггеры
- **MyFurniture** - Добавьте кастомную мебель на свой сервер Minecraft
- **ExecutableCrafting** - Создавайте кастомные рецепты крафта
- **ExecutableGems** - Самоцветы, руны и рунные слова, которые вставляются в любой предмет

## 🛠️ Инструменты для всех плагинов

Все плагины используют SCore, который предоставляет набор мощных инструментов:

- **Custom Commands** - Выполняйте сложные последовательности команд
- **Custom Conditions** - Создавайте условную логику для своих предметов и блоков
- **Custom Projectiles** - Настраивайте уникальное поведение снарядов
- **SCore Variables** - Динамическая система переменных
- **SCore Particles** - Продвинутые эффекты частиц
