# Partikel epik

Di halaman ini Anda akan mempelajari berbagai metode untuk menambahkan partikel ke item Anda, mulai dari yang paling dasar hingga yang paling epik/canggih.

### 1) Perintah PARTICLE

Perintah ini memiliki keterbatasan bentuk, misalnya partikel dust tidak berfungsi dengan baik, dll. Karena itu perintah ini bukan yang terbaik. Anda dapat melihat tautan berikut

[**PERINTAH PARTICLE EI**](/tools-for-all-plugins/custom-commands/player-and-target-commands#particle)

### 2) Perintah particle vanilla

Dengan menggabungkan perintah ini dengan tutorial "[**cara menggunakan perintah vanilla**](executableitems/questions-or-guides/frequently-asked-questions/how-to-use-vanilla-commands)", Anda akan mendapatkan sesuatu seperti

```
execute at <placeholder> run particle....
```

Di sini Anda lebih bebas dibandingkan yang sebelumnya, tetapi sekali lagi, bentuknya hanya berupa balok (parallelepiped), bukan yang paling epik.

Jika Anda tidak tahu cara menggunakan perintah particle, lihat tautan berikut

[**Cara menggunakan perintah particle**](/executableitems/questions-or-guides/utilities#general-particle-cmd)

[**Generator perintah particle**](https://www.gamergeeks.net/apps/minecraft/particle-command-generator)

### 3) Generator partikel

Di sini Anda akan menemukan beberapa halaman web untuk membuat bentuk partikel. Halaman-halaman ini SANGAT berguna untuk membuat berbagai hal.

Sebagian besar bekerja berdasarkan persamaan matematika, jadi Anda memerlukan sedikit pengetahuan awal tentang hal ini. Untuk melihat cara kerja persamaan matematika, Anda dapat menggunakan GEOGEBRA

Untuk mengekstrak perintah dari satu baris atau dari sebuah fungsi menjadi perintah-perintah terpisah, Anda juga memerlukan sedikit pengetahuan awal.

[**Tautan pertama**](https://100awesome.net/videos/particle-generator/) adalah generator partikel berbasis satu command block, dan tersedia juga tutorial videonya

[**Tautan kedua**](https://cloudwolfyt.github.io/pages/gens/particle-plots.html) lebih baik, karena bekerja dengan persamaan matematika sehingga Anda bisa mendapatkan jauh lebih banyak bentuk dibandingkan yang sebelumnya. Ada juga [**tautan video**](https://youtu.be/\_mi1B0IeVWw).

### 4) Score particles

Ada juga Score particles yang menyertakan banyak bentuk siap pakai yang dapat Anda edit dengan parameter khususnya untuk menampilkan apa pun yang Anda inginkan. Info lebih lanjut ada di tutorial [**Score particles**]/tools-for-all-plugins-score/score-particles.md).
