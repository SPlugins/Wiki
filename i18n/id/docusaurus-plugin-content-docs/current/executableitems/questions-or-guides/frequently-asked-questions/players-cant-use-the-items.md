# Pemain tidak dapat menggunakan item

Jika Anda sudah membuat item dan ingin mengujinya dengan pemain tanpa op dan tanpa izin, pemain tersebut akan mencoba menggunakannya dan menerima pesan ini:

![](https://media.ssomar.com/m/docs-img-image-109.png)

Hal itu terjadi karena mereka tidak memiliki izin untuk menggunakan item tersebut. Karena tidak ada yang ingin memberikan op kepada pemain, Anda harus memberikan izin yang benar kepada pemain default Anda. Untuk itu, cukup lihat bagian [**Permissions**](https://splugins.net/docs/executableitems/commands-and-permissions#permissions), dan baca Tip di bagian atas halaman ^^

Gambar ini:

:::info
Untuk berjaga-jaga, **YA** -> Anda wajib memiliki plugin izin untuk mengelola izin item bagi para pemain.

\
**Jika Anda TIDAK MEMILIKI PLUGIN IZIN dan TIDAK INGIN MENAMBAHKANNYA, satu-satunya cara adalah memberikan op kepada pemain Anda. Jika Anda tidak menginginkan itu, cukup unduh sebuah plugin izin**
:::
