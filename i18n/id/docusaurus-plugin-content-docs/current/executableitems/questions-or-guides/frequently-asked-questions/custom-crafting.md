# Crafting Kustom

## Apakah ExecutableItems Mendukung Crafting Kustom?

ExecutableItems **tidak** memiliki mekanisme crafting kustom bawaan. Untuk membuat resep kustom bagi ExecutableItems, Anda perlu menggunakan plugin crafting kustom pihak ketiga.

Anda dapat menggunakan plugin kami [ExecutableCrafting](https://modrinth.com/plugin/executablecrafting)
Namun jika Anda ingin menggunakan plugin lain, itu juga bisa, umumnya plugin tersebut kompatibel dengan ExecutableItems.
