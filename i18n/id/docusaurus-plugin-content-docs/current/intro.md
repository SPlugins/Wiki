# Selamat Datang di Wiki Score Plugins

Selamat datang di dokumentasi lengkap untuk semua Score Plugins!

Di sini Anda akan menemukan informasi detail tentang:

## 🎮 Plugin Utama

- **ExecutableItems** - Buat item kustom dengan kemampuan dan perintah unik
- **ExecutableBlocks** - Buat blok kustom dengan fungsi khusus
- **ExecutableEvents** - Buat event dan trigger kustom
- **MyFurniture** - Tambahkan furnitur kustom ke server Minecraft Anda
- **ExecutableCrafting** - Buat resep crafting kustom
- **ExecutableGems** - Gems, runes, dan runewords yang dapat dipasang ke item apa pun

## 🛠️ Tools untuk Semua Plugin

Semua plugin menggunakan SCore yang memiliki sekumpulan tools canggih:

- **Custom Commands** - Jalankan rangkaian perintah yang kompleks
- **Custom Conditions** - Buat logika kondisional untuk item dan blok Anda
- **Custom Projectiles** - Rancang perilaku projectile yang unik
- **SCore Variables** - Sistem variabel dinamis
- **SCore Particles** - Efek partikel tingkat lanjut

## 🚀 Memulai

Jelajahi [Peta Situs Dokumentasi Lengkap](/sitemap) untuk melihat semua halaman yang tersedia, atau pilih sebuah plugin dari sidebar untuk mulai menjelajah. Setiap bagian plugin berisi:

- Panduan instalasi
- Referensi konfigurasi
- Pertanyaan yang sering diajukan
- Tutorial dan contoh
- Dokumentasi API
