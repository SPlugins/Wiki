# 欢迎来到 Score Plugins Wiki

欢迎阅读所有 Score Plugins 的完整文档！

在这里你可以找到以下内容的详细信息：

## 🎮 主要插件

- **ExecutableItems** - 创建拥有独特能力和命令的自定义物品
- **ExecutableBlocks** - 创建拥有特殊功能的自定义方块
- **ExecutableEvents** - 创建自定义事件和触发器
- **MyFurniture** - 为你的 Minecraft 服务器添加自定义家具
- **ExecutableCrafting** - 创建自定义合成配方
- **ExecutableGems** - 可镶嵌到任意物品中的宝石、符文和符文之语

## 🛠️ 适用于所有插件的工具

所有插件都使用 SCore，它提供了一套强大的工具：

- **Custom Commands** - 执行复杂的命令序列
- **Custom Conditions** - 为你的物品和方块创建条件逻辑
- **Custom Projectiles** - 设计独特的投射物行为
- **SCore Variables** - 动态变量系统
- **SCore Particles** - 高级粒子效果
