# 玩家无法使用物品

如果你已经制作好了自己的物品，并想用一个没有 op、没有权限的玩家来测试，他们尝试使用时会收到这条消息：

![](https://media.ssomar.com/m/docs-img-image-109.png)

这是因为他们没有使用这些物品的权限。既然没有人愿意给玩家 op，你就需要为默认玩家授予正确的权限。为此，只需查看 [**Permissions**](https://splugins.net/docs/executableitems/commands-and-permissions#permissions) 部分，并阅读页面顶部的提示 ^^

这张图片：

:::info
以防万一，**是的** -> 需要有一个权限插件来管理玩家使用物品的权限。

\
**如果你没有权限插件，也不想添加，唯一的办法就是给玩家 op。如果你不想这样做，请下载一个权限插件**
:::
