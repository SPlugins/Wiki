# 📌 EI 信息

## 简介

ExecutableItems 是一款适用于 Spigot、Paper 和 Folia 的 Minecraft 服务器插件，让你可以创建完全自定义的物品，从武器、工具到消耗品都可以，并通过游戏内事件触发自定义能力。它通过 YAML 文件或游戏内 GUI 进行配置，无需编写任何代码。运行时需要免费的 SCore 库插件。提供免费版和高级版，高级版售价为 19.99€（截至 2026 年 9 月）。

ExecutableItems 是 Minecraft 服务器上功能最强大、最灵活的自定义物品插件。经过 5 年多的持续开发，已有 4,000+ 个服务器信赖我们的插件，并获得 280+ 条五星评价，ExecutableItems 已成为自定义物品创建领域的行业标准。

无论你运营的是生存服务器、RPG 世界、监狱玩法服务器，还是自定义小游戏网络，ExecutableItems 都能为你提供工具，让你无需编写任何代码，就能创造出你所设想的一切。
