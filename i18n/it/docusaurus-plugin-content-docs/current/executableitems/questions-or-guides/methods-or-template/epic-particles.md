# Particelle epiche

In questa pagina imparerai diversi metodi per aggiungere particelle al tuo item, dai più semplici ai più epici/avanzati.

### 1) Comando PARTICLE

Questo comando ha limiti per quanto riguarda la forma, nel caso della particella dust non funziona bene, ecc., per questo non è il migliore. Puoi dare un'occhiata a questo link

[**COMANDO PARTICLE EI**](/tools-for-all-plugins/custom-commands/player-and-target-commands#particle)

### 2) Comando particle vanilla

Combinando questo comando con il tutorial «[**come usare i comandi vanilla**](executableitems/questions-or-guides/frequently-asked-questions/how-to-use-vanilla-commands)» otterrai qualcosa come

```
execute at <placeholder> run particle....
```

Qui hai più libertà rispetto al precedente, ma anche in questo caso la forma è solo un parallelepipedo, non è la cosa più epica.

Se non sai come usare il comando particle, dai un'occhiata a questo link

[**Come usare il comando particle**](/executableitems/questions-or-guides/utilities#general-particle-cmd)

[**Generatore di comandi particle**](https://www.gamergeeks.net/apps/minecraft/particle-command-generator)

### 3) Generatori di particelle

Qui trovi alcune pagine web per generare forme di particelle, sono MOLTO utili per creare cose.

La maggior parte funziona basandosi su equazioni matematiche, quindi serve un po' di conoscenza preliminare in materia. Per dare un'occhiata a come funzionano le equazioni matematiche puoi usare GEOGEBRA

Per estrarre i comandi da una singola riga o da una funzione e ottenere comandi separati serve anche un po' di conoscenza preliminare.

Il [**primo link**](https://100awesome.net/videos/particle-generator/) è un generatore di particelle basato su un singolo command block, c'è anche un video tutorial

Il [**secondo link**](https://cloudwolfyt.github.io/pages/gens/particle-plots.html) è migliore, funziona con equazioni matematiche, quindi puoi ottenere molte più forme rispetto al precedente. C'è anche un [**link a un video**](https://youtu.be/\_mi1B0IeVWw).

### 4) Score particles

Esistono anche le Score particles, che includono molte forme già pronte che puoi modificare con i loro parametri specifici per mostrare ciò che desideri. Maggiori informazioni nel tutorial di [**Score particles**]/tools-for-all-plugins-score/score-particles.md).
