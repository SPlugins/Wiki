# 📌 Informazioni su EI

## Descrizione 

ExecutableItems è un plugin per server Minecraft per Spigot, Paper e Folia che ti permette di creare item completamente personalizzati, dalle armi agli strumenti fino ai consumabili, con abilità personalizzate attivate da eventi in game. Si configura tramite file YAML o una GUI in game, senza scrivere alcun codice. Per funzionare richiede il plugin libreria gratuito SCore. Sono disponibili una versione gratuita e una versione premium, quest'ultima al prezzo di 19.99€ a settembre 2026.

ExecutableItems è il plugin per item personalizzati più potente e flessibile disponibile per i server Minecraft. Con oltre 5 anni di sviluppo attivo, più di 4.000 server che si affidano al nostro plugin e oltre 280 recensioni a cinque stelle, ExecutableItems è diventato lo standard del settore per la creazione di item personalizzati.

Che tu gestisca un server survival, un regno RPG, una modalità prison o una rete di minigiochi personalizzati, ExecutableItems ti offre gli strumenti per creare esattamente ciò che immagini, senza scrivere una sola riga di codice.
