# Benvenuto nella wiki di Score Plugins

Benvenuto nella documentazione completa di tutti gli Score Plugins!

Qui troverai informazioni dettagliate su:

## 🎮 Plugin principali

- **ExecutableItems** - Crea item personalizzati con abilità e comandi unici
- **ExecutableBlocks** - Crea blocchi personalizzati con funzioni speciali
- **ExecutableEvents** - Crea eventi e trigger personalizzati
- **MyFurniture** - Aggiungi arredi personalizzati al tuo server Minecraft
- **ExecutableCrafting** - Crea ricette di crafting personalizzate
- **ExecutableGems** - Gemme, rune e runewords incastonate in qualsiasi item

## 🛠️ Strumenti per tutti i plugin

Tutti i plugin usano SCore, che offre una serie di strumenti potenti:

- **Custom Commands** - Esegui sequenze complesse di comandi
- **Custom Conditions** - Crea una logica condizionale per i tuoi item e i tuoi blocchi
- **Custom Projectiles** - Progetta comportamenti unici per i proiettili
- **SCore Variables** - Sistema di variabili dinamiche
- **SCore Particles** - Effetti particellari avanzati
