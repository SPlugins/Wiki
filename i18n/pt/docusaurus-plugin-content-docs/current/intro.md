# Bem-vindo à Wiki dos Score Plugins

Bem-vindo à documentação completa de todos os Score Plugins!

Aqui você encontra informações detalhadas sobre:

## 🎮 Plugins principais

- **ExecutableItems** - Crie itens personalizados com habilidades e comandos únicos
- **ExecutableBlocks** - Crie blocos personalizados com funções especiais
- **ExecutableEvents** - Crie eventos e triggers personalizados
- **MyFurniture** - Adicione móveis personalizados ao seu servidor Minecraft
- **ExecutableCrafting** - Crie receitas de criação personalizadas
- **ExecutableGems** - Gemas, runas e runewords encaixadas em qualquer item

## 🛠️ Ferramentas para todos os plugins

Todos os plugins usam o SCore, que oferece um conjunto de ferramentas poderosas:

- **Custom Commands** - Execute sequências complexas de comandos
- **Custom Conditions** - Crie lógica condicional para seus itens e blocos
- **Custom Projectiles** - Projete comportamentos únicos de projéteis
- **SCore Variables** - Sistema de variáveis dinâmicas
- **SCore Particles** - Efeitos de partículas avançados
