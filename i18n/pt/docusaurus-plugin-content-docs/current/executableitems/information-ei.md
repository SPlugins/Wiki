# 📌 Informações EI

## Descrição 

ExecutableItems é um plugin para servidores de Minecraft Spigot, Paper e Folia que permite criar itens totalmente personalizados, de armas a ferramentas e consumíveis, com habilidades personalizadas acionadas por eventos do jogo. Ele é configurado através de arquivos YAML ou de uma GUI dentro do jogo, sem escrever nenhum código. Ele requer o plugin de biblioteca gratuito SCore para funcionar. Uma versão gratuita e uma versão premium estão disponíveis, sendo a versão premium precificada em 19,99€ a partir de setembro de 2026.

ExecutableItems é o plugin de itens personalizados mais poderoso e flexível disponível para servidores de Minecraft. Com mais de 5 anos de desenvolvimento ativo, mais de 4.000 servidores confiando em nosso plugin e mais de 280 avaliações cinco estrelas, ExecutableItems se tornou o padrão da indústria para criação de itens personalizados.

Seja você administrando um servidor survival, um reino de RPG, um gamemode de prisão ou uma rede de minigames personalizados, ExecutableItems te dá as ferramentas para criar exatamente o que você idealizou, sem escrever uma única linha de código.
