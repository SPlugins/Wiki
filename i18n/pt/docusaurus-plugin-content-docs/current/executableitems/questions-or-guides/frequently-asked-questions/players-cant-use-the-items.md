# Jogadores não conseguem usar os itens

Se for o caso de você já ter criado seus itens e quer testar com um jogador sem op, sem perms, eles tentam e recebem esta mensagem:

![](https://media.ssomar.com/m/docs-img-image-109.png)

Isso acontece porque eles não têm permissão para usar os itens, já que ninguém gostaria de dar op para os jogadores, você precisa dar as permissões corretas para seus jogadores padrão, para isso, basta verificar a seção de [**Permissions**](https://splugins.net/docs/executableitems/commands-and-permissions#permissions), e ler a Tip no topo da página ^^

Esta imagem:

:::info
Só para garantir, **SIM** -> É necessário ter um plugin de perms para gerenciar as perms dos itens para os jogadores.

\
**Se você NÃO TEM UM PLUGIN DE PERMS e NÃO QUER ADICIONAR UM, a única forma é dar op para seus jogadores, se você não quer isso, basta baixar um plugin de perms**
:::
