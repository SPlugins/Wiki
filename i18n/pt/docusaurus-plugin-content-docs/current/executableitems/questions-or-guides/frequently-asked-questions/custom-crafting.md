# Custom Crafting

## O ExecutableItems Suporta Custom Crafting?

O ExecutableItems **não** possui mecânicas de custom crafting integradas. Para criar receitas personalizadas para o ExecutableItems, você precisa usar um plugin de custom crafting de terceiros.

Você pode usar o nosso plugin [ExecutableCrafting](https://modrinth.com/plugin/executablecrafting)
Mas se você quiser usar outro, pode, geralmente eles são compatíveis com o ExecutableItems.
