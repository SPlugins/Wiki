# Partículas épicas

Nesta página você vai aprender diferentes métodos para adicionar partículas ao seu item, do mais básico ao mais épico/avançado.

### 1) Comando PARTICLE

Esse comando tem limitações de formato, no caso da partícula dust não funciona bem, etc, por isso não é a melhor opção, você pode dar uma olhada nesse link

[**COMANDO PARTICLE EI**](/tools-for-all-plugins/custom-commands/player-and-target-commands#particle)

### 2) Comando de partícula vanilla

Combinando esse comando com o tutorial de "[**como usar comandos vanilla**](executableitems/questions-or-guides/frequently-asked-questions/how-to-use-vanilla-commands)" você vai conseguir algo como

```
execute at <placeholder> run particle....
```

Aqui você tem mais liberdade que no anterior, mas, de novo, o formato é apenas um paralelepípedo, não é a coisa mais épica.

Se você não sabe como usar o comando particle, dá uma olhada nesse link

[**Como usar o comando particle**](/executableitems/questions-or-guides/utilities#general-particle-cmd)

[**Gerador de comando particle**](https://www.gamergeeks.net/apps/minecraft/particle-command-generator)

### 3) Geradores de partículas

Aqui você vai encontrar algumas páginas web para gerar formatos de partículas, que são MUITO úteis para criar coisas.

A maioria delas funciona com base em equações matemáticas, então você precisa ter um pouco de conhecimento prévio sobre isso. Para ver como as equações matemáticas funcionam, você pode usar o GEOGEBRA

Para extrair os comandos de uma linha única ou de uma função para comandos divididos, você também precisa de algum conhecimento prévio.

O [**primeiro link**](https://100awesome.net/videos/particle-generator/) é um gerador de partículas baseado em um command block, você também tem um tutorial em vídeo

O [**segundo link**](https://cloudwolfyt.github.io/pages/gens/particle-plots.html) é melhor, ele funciona com equações matemáticas então você consegue muito mais formatos do que no anterior. Também tem um [**link de vídeo**](https://youtu.be/\_mi1B0IeVWw).

### 4) Score particles

Também existem os Score particles, que incluem muitos formatos pré-feitos que você pode editar com os parâmetros específicos deles para exibir o que você quiser exibir. Mais informações no tutorial de [**Score particles**]/tools-for-all-plugins-score/score-particles.md).
