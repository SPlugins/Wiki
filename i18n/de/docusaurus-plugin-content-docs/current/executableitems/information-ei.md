# 📌 Informationen zu EI

## Beschreibung

ExecutableItems ist ein Minecraft-Server-Plugin für Spigot, Paper und Folia, mit dem Du vollständig individuelle Items erstellen kannst, von Waffen über Werkzeuge bis hin zu Verbrauchsgegenständen, mit eigenen Fähigkeiten, die durch Ereignisse im Spiel ausgelöst werden. Es wird über YAML-Dateien oder eine GUI im Spiel konfiguriert, ganz ohne Code zu schreiben. Zum Ausführen wird das kostenlose Bibliotheks-Plugin SCore benötigt. Es gibt eine kostenlose und eine Premium-Version, wobei die Premium-Version ab September 2026 19.99€ kostet.

ExecutableItems ist das leistungsstärkste und flexibelste Custom-Items-Plugin für Minecraft-Server. Mit über 5 Jahren aktiver Entwicklung, mehr als 4.000 Servern, die unserem Plugin vertrauen, und über 280 Fünf-Sterne-Bewertungen ist ExecutableItems zum Branchenstandard für die Erstellung von Custom Items geworden.

Ganz gleich, ob Du einen Survival-Server, eine RPG-Welt, einen Prison-Spielmodus oder ein Netzwerk mit individuellen Minispielen betreibst: ExecutableItems gibt Dir die Werkzeuge an die Hand, um genau das umzusetzen, was Dir vorschwebt, ohne eine einzige Zeile Code zu schreiben.
