# Partículas épicas

En esta página aprenderás distintos métodos para añadir partículas a tu ítem, desde los más básicos hasta los más épicos/avanzados.

### 1) Comando PARTICLE

Este comando tiene limitaciones de forma, por ejemplo, en el caso de la partícula dust no funciona bien, etc, por eso no es la mejor opción, puedes echar un vistazo a este enlace

[**COMANDO PARTICLE DE EI**](/tools-for-all-plugins/custom-commands/player-and-target-commands#particle)

### 2) Comando de partículas vanilla

Combinando este comando con el tutorial de "[**cómo usar comandos vanilla**](executableitems/questions-or-guides/frequently-asked-questions/how-to-use-vanilla-commands)" obtendrás algo como

```
execute at <placeholder> run particle....
```

Aquí tienes más libertad que en el anterior, pero de nuevo, la forma es solo un paralelepípedo, no es lo más épico.

Si no sabes cómo usar el comando particle, échale un vistazo a este enlace

[**Cómo usar el comando particle**](/executableitems/questions-or-guides/utilities#general-particle-cmd)

[**Generador de comandos de partículas**](https://www.gamergeeks.net/apps/minecraft/particle-command-generator)

### 3) Generadores de partículas

Aquí tendrás algunas páginas web para generar formas de partículas, son MUY útiles para crear cosas.

La mayoría funcionan basándose en ecuaciones matemáticas, así que necesitas tener un poco de conocimiento previo sobre esto. Para ver cómo funcionan las ecuaciones matemáticas puedes usar GEOGEBRA

Para extraer los comandos de una línea o de una función a comandos divididos también necesitas algo de conocimiento previo.

El [**primer enlace**](https://100awesome.net/videos/particle-generator/) es un generador de partículas basado en un bloque de comandos, también tienes un video tutorial

El [**segundo enlace**](https://cloudwolfyt.github.io/pages/gens/particle-plots.html) es mejor, funciona con ecuaciones matemáticas así que puedes conseguir muchas más formas que con el anterior. También hay un [**enlace de video**](https://youtu.be/\_mi1B0IeVWw).

### 4) Score particles

También existen las Score particles, que incluyen muchas formas prediseñadas que puedes editar con sus parámetros específicos para mostrar lo que quieras mostrar. Más información en el tutorial de [**Score particles**]/tools-for-all-plugins-score/score-particles.md).
