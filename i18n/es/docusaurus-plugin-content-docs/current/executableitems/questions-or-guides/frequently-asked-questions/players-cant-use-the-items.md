# Los jugadores no pueden usar los ítems

Si ya has creado tus ítems y quieres probarlos con un jugador sin op, sin permisos, al intentarlo recibirán este mensaje:

![](https://media.ssomar.com/m/docs-img-image-109.png)

Esto se debe a que no tienen permisos para usar los ítems, y como a nadie le gustaría dar op a sus jugadores, tienes que asignar los permisos correctos a tus jugadores por defecto. Para esto, simplemente revisa la sección de [**Permissions**](https://splugins.net/docs/executableitems/commands-and-permissions#permissions) y lee el Tip que aparece en la parte superior de la página ^^

Esta imagen:

:::info
Solo para que quede claro, **SÍ** -> Es necesario tener un plugin de permisos para gestionar los permisos de los ítems para los jugadores.

\
**Si NO TIENES UN PLUGIN DE PERMISOS y NO QUIERES AÑADIR UNO, la única forma es dar op a tus jugadores. Si no quieres eso, simplemente descarga un plugin de permisos**
:::
