# Crafteo Personalizado

## ¿ExecutableItems Soporta el Crafteo Personalizado?

ExecutableItems **no** tiene mecánicas de crafteo personalizado integradas. Para crear recetas personalizadas para ExecutableItems, necesitas usar un plugin de crafteo personalizado de terceros.

Puedes usar nuestro plugin [ExecutableCrafting](https://modrinth.com/plugin/executablecrafting)
Pero si quieres usar otro, puedes hacerlo; generalmente son compatibles con ExecutableItems.
