# 📌 Información EI

## Descripción 

ExecutableItems es un plugin para servidores de Minecraft compatible con Spigot, Paper y Folia que te permite crear ítems totalmente personalizados, desde armas hasta herramientas y consumibles, con habilidades personalizadas activadas por eventos del juego. Se configura mediante archivos YAML o una GUI dentro del juego, sin escribir código. Requiere el plugin gratuito SCore para funcionar. Hay disponible una versión gratuita y una versión premium, con la versión premium a un precio de 19.99€ a partir de septiembre de 2026.

ExecutableItems es el plugin de ítems personalizados más potente y flexible disponible para servidores de Minecraft. Con más de 5 años de desarrollo activo, más de 4.000 servidores que confían en nuestro plugin y más de 280 reseñas de cinco estrellas, ExecutableItems se ha convertido en el estándar de la industria para la creación de ítems personalizados.

Tanto si administras un servidor de survival, un reino de RPG, un gamemode de prisión o una red de minijuegos personalizados, ExecutableItems te ofrece las herramientas para crear exactamente lo que imaginas, sin escribir una sola línea de código.
