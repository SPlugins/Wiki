# Bienvenido a la wiki de Score Plugins

¡Te damos la bienvenida a la documentación completa de todos los Score Plugins!

Aquí encontrarás información detallada sobre:

## 🎮 Plugins principales

- **ExecutableItems** - Crea ítems personalizados con habilidades y comandos únicos
- **ExecutableBlocks** - Crea bloques personalizados con funciones especiales
- **ExecutableEvents** - Crea eventos y triggers personalizados
- **MyFurniture** - Añade muebles personalizados a tu servidor de Minecraft
- **ExecutableCrafting** - Crea recetas de crafteo personalizadas
- **ExecutableGems** - Gemas, runas y runewords engarzadas en cualquier ítem

## 🛠️ Herramientas para todos los plugins

Todos los plugins usan SCore, que incluye un conjunto de herramientas potentes:

- **Custom Commands** - Ejecuta secuencias de comandos complejas
- **Custom Conditions** - Crea lógica condicional para tus ítems y bloques
- **Custom Projectiles** - Diseña comportamientos únicos de proyectiles
- **SCore Variables** - Sistema de variables dinámicas
- **SCore Particles** - Efectos de partículas avanzados

## 🚀 Primeros pasos

Consulta el [mapa del sitio con toda la documentación](/sitemap) para ver todas las páginas disponibles, o selecciona un plugin en la barra lateral para empezar a explorar. Cada sección de plugin contiene:

- Guías de instalación
- Referencias de configuración
- Preguntas frecuentes

- Documentación de la API
