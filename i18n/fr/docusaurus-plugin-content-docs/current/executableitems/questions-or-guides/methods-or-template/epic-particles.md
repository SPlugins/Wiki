# Particules épiques

Dans cette page, vous allez découvrir différentes méthodes pour ajouter des particules à votre item, des plus basiques aux plus épiques/avancées.

### 1) Commande PARTICLE

Cette commande a des limites de forme : dans le cas de la particule dust, elle ne fonctionne pas bien, etc. C'est pourquoi ce n'est pas la meilleure option. Vous pouvez consulter ce lien :

[**COMMANDE PARTICLE EI**](/tools-for-all-plugins/custom-commands/player-and-target-commands#particle)

### 2) Commande particle vanilla

En combinant cette commande avec le tutoriel « [**comment utiliser les commandes vanilla**](executableitems/questions-or-guides/frequently-asked-questions/how-to-use-vanilla-commands) », vous obtiendrez quelque chose comme :

```
execute at <placeholder> run particle....
```

Ici, vous avez plus de liberté qu'avec la précédente, mais là encore, la forme n'est qu'un parallélépipède, ce qui n'est pas le plus épique.

Si vous ne savez pas utiliser la commande particle, consultez ce lien :

[**Comment utiliser la commande particle**](/executableitems/questions-or-guides/utilities#general-particle-cmd)

[**Générateur de commande particle**](https://www.gamergeeks.net/apps/minecraft/particle-command-generator)

### 3) Générateurs de particules

Voici quelques pages web pour générer des formes de particules, elles sont TRÈS utiles pour créer des effets.

La plupart fonctionnent à partir d'équations mathématiques, vous avez donc besoin de quelques connaissances préalables dans ce domaine. Pour voir comment fonctionnent les équations mathématiques, vous pouvez utiliser GEOGEBRA.

Pour extraire les commandes à partir d'une seule ligne ou d'une fonction et obtenir des commandes séparées, vous avez aussi besoin de quelques connaissances préalables.

Le [**premier lien**](https://100awesome.net/videos/particle-generator/) est un générateur de particules basé sur un seul command block, avec également un tutoriel vidéo.

Le [**deuxième lien**](https://cloudwolfyt.github.io/pages/gens/particle-plots.html) est meilleur : il fonctionne avec des équations mathématiques, ce qui permet d'obtenir beaucoup plus de formes que le précédent. Il existe aussi un [**lien vidéo**](https://youtu.be/\_mi1B0IeVWw).

### 4) Score particles

Il existe également les Score particles, qui incluent beaucoup de formes prédéfinies que vous pouvez modifier avec leurs paramètres spécifiques pour afficher ce que vous souhaitez. Plus d'infos dans le tutoriel des [**Score particles**]/tools-for-all-plugins-score/score-particles.md).
