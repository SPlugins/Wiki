# Les joueurs ne peuvent pas utiliser les items

Si vous avez déjà créé vos items et que vous voulez les tester avec un joueur sans op, sans permissions, celui-ci essaie de les utiliser et reçoit ce message :

![](https://media.ssomar.com/m/docs-img-image-109.png)

C'est parce qu'il n'a pas la permission d'utiliser les items. Comme personne ne veut donner op aux joueurs, vous devez donner les bonnes permissions à vos joueurs par défaut. Pour cela, consultez simplement la section [**Permissions**](https://splugins.net/docs/executableitems/commands-and-permissions#permissions) et lisez le Tip en haut de la page ^^

Cette image :

:::info
Au cas où : **OUI** -> Il est nécessaire d'avoir un plugin de permissions pour gérer les permissions des items pour les joueurs.

\
**Si vous N'AVEZ PAS DE PLUGIN DE PERMISSIONS et que vous NE VOULEZ PAS EN AJOUTER un, la seule solution est de donner op à vos joueurs. Si vous ne le souhaitez pas, téléchargez simplement un plugin de permissions**
:::
