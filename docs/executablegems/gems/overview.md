# 💎 List of gems

ExecutableGems ships **37 gems** in **7 categories**, and **12 runewords**. Every one of them is a plain YAML file you can edit, disable or delete.

![All the gems around a Celestial Forge](https://media.ssomar.com/m/docs-img-eg-hero-wall.jpg)

**Loot weight** is how likely a gem is against the others in monster drops, chests and appraisals: 10 is a normal gem, 1 a relic. `-` means the gem is never found at random.
